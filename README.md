# VOBLOCK

เกมต่อบล็อก 3 มิติบนเบราว์เซอร์ เล่นได้ทั้งคอม แท็บเล็ต และมือถือ รองรับห้องผู้เล่นหลายคนและบันทึกงานเป็น JSON

## ไฟล์ในโปรเจกต์
- `index.html` โครงหน้าเว็บและหน้าเครดิต
- `style.css` สไตล์และ UI
- `app.js` ตรรกะเกมทั้งหมด (3D, การควบคุม, มัลติเพลเยอร์, เซฟ/โหลด)

## วิธีเปิดบน GitHub Pages
1. สมัคร/ล็อกอิน github.com แล้วกด **New repository** ตั้งชื่อ เช่น `voblock` เลือก **Public** แล้วกด Create
2. กด **uploading an existing file** แล้วลากไฟล์ทั้งหมดในโฟลเดอร์นี้ (`index.html`, `style.css`, `app.js`, `README.md`) ไปวาง (ต้องแตก zip ก่อน และไฟล์ต้องอยู่ที่ราก ไม่ใช่ในโฟลเดอร์ย่อย) แล้วกด **Commit changes**
3. ไปที่ **Settings → Pages**
4. ที่ **Source** เลือก **Deploy from a branch** แล้วเลือก Branch เป็น `main` และโฟลเดอร์ `/ (root)` กด **Save**
5. รอ 1-2 นาที จะได้ลิงก์ `https://ชื่อผู้ใช้.github.io/voblock/`
6. เปิดลิงก์แล้วกด **เชิญเพื่อน** เพื่อสร้างห้องและคัดลอกลิงก์ให้เพื่อน

## หมายเหตุ
- ต้องเปิดผ่านลิงก์ https (GitHub Pages ให้อยู่แล้ว) มัลติเพลเยอร์จึงทำงานได้
- มัลติเพลเยอร์ใช้เซิร์ฟเวอร์สัญญาณฟรีของ PeerJS ถ้าเครือข่ายบางแห่งเชื่อมต่อไม่ได้ อาจต้องตั้ง TURN server เพิ่ม
- ทดสอบในเครื่องได้โดยรัน `python3 -m http.server` ในโฟลเดอร์นี้ แล้วเปิด http://localhost:8000
