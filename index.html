เลือกบล็อก

VOBLOCK

สตูดิโอต่อบล็อก 3 มิติ บนเบราว์เซอร์

VOBLOCK คือเกมสร้างสรรค์สำหรับต่อบล็อกสี่เหลี่ยมเป็นรูปทรงตามจินตนาการ ใช้เล่นได้ทั้งคอมพิวเตอร์ แท็บเล็ต และมือถือ ชวนเพื่อนเข้าห้องมาสร้างงานด้วยกัน และบันทึกผลงานเป็นไฟล์ JSON ได้

เครดิต

ไอเดียและแนวคิดเกม
เป็นของ smilemssz ผู้คิดคอนเซ็ปต์ทั้งหมด เช่น เกมต่อบล็อก 3 มิติบนเบราว์เซอร์ ดีไซน์มินิมอล เมนูรอบชิ้นงาน แคปซูลเพิ่มบล็อก ห้องมัลติเพลเยอร์ และการบันทึกเป็นไฟล์ JSON

การเขียนโค้ดทั้งหมด
เขียนโดย Claude (รุ่น Claude Sonnet 5.5) ซึ่งเป็นผู้ช่วย AI ที่พัฒนาโดย Anthropic โค้ดทุกบรรทัดในโปรเจกต์นี้ ทั้ง HTML, CSS และ JavaScript ถูกสร้างโดย Claude จากไอเดียและคำสั่งของเจ้าของไอเดีย

สิ่งที่ Claude ทำ: ระบบฉาก 3 มิติและแสงเงา, การวางบล็อกบนตารางพร้อมการซ้อนชั้น, การลาก/หมุน/ลบ, เมนูรอบชิ้นงานและ outline ตอนเลือก, ตัวแก้สีและรูปภาพ, แผงเลือกบล็อกที่ปรับตามมือถือ/แท็บเล็ต/คอม, เมนูคลิกขวา, ระบบห้องผู้เล่นหลายคน, การบันทึกและโหลดไฟล์ JSON และหน้าเครดิตนี้

ข้อควรทราบ

VOBLOCK เป็นผลงานอิสระที่ออกแบบขึ้นเอง รูปทรงบล็อกทั้งหมดสร้างด้วยโค้ดของเกมนี้ ไม่เกี่ยวข้อง ไม่ได้รับการสนับสนุน และไม่ได้รับการรับรองจากผู้ผลิตของเล่นตัวต่อรายใด ชื่อและเครื่องหมายการค้าอื่นที่อาจถูกกล่าวถึงเป็นสิทธิ์ของเจ้าของนั้น ๆ
